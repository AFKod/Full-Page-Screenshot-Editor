# Full Page Screenshot Editor

**Full Page Screenshot Editor** — расширение для Google Chrome, предназначенное для создания скриншотов веб-страниц целиком и обрезки нужных фрагментов во встроенном редакторе.

Идея проекта — объединить захват длинных страниц, простое редактирование и экспорт изображений в одном инструменте без необходимости пользоваться сторонними онлайн-сервисами.

> **Статус проекта:** в разработке. Репозиторий создан, реализация расширения и публикация исходного кода запланированы. Перечисленные ниже функции описывают целевую функциональность, а не уже выпущенную версию.

## Возможности

Планируется реализовать:

- **Захват страницы целиком.** Автоматическая прокрутка и объединение отдельных снимков в одно изображение.
- **Встроенный редактор.** Просмотр результата в отдельной вкладке Chrome.
- **Обрезка изображения.** Выделение произвольной области мышью и изменение границ выделения.
- **Экспорт в PNG и JPEG.** Сохранение как полного скриншота, так и выбранного фрагмента.
- **Копирование в буфер обмена.** Быстрая вставка изображения в другие приложения.
- **Локальная обработка.** Захват и редактирование без отправки изображений на внешние серверы.
- **Простой интерфейс.** Минимум действий от нажатия на иконку до готового файла.

## Как это должно работать

1. Откройте нужную веб-страницу в Google Chrome.
2. Нажмите на значок расширения.
3. Дождитесь захвата и объединения содержимого страницы.
4. В открывшемся редакторе выделите интересующую область.
5. Сохраните изображение в PNG/JPEG или скопируйте его в буфер обмена.

## Установка

**Расширение пока недоступно для установки:** исходный код ещё не опубликован.

После появления первой рабочей версии установка из репозитория будет выглядеть так:

1. Скачайте исходный код через **Code → Download ZIP** и распакуйте архив.
2. Откройте в Chrome адрес `chrome://extensions/`.
3. Включите **Режим разработчика**.
4. Нажмите **Загрузить распакованное расширение** (*Load unpacked*).
5. Выберите папку готового расширения, содержащую `manifest.json`. Если проект будет использовать сборку, сначала выполните инструкции по сборке из будущей документации.

## Ограничения

Некоторые сайты используют бесконечную прокрутку, вложенные области прокрутки, динамическую загрузку или закреплённые элементы. Такие страницы могут потребовать дополнительной обработки. Системные страницы Chrome и другие защищённые вкладки также могут быть недоступны для захвата из-за ограничений браузера.
