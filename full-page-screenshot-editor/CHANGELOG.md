# История изменений

## 1.0.3 — 17 октября 2026

- Заметная кнопка «Очистить всё» в шапке редактора и полная очистка в библиотеке.
- Очистка отменяет захват с восстановлением страницы, блокирует новые сеансы, сбрасывает все открытые редакторы и удаляет всю IndexedDB, включая ошибки и кадры без метаданных. Отменённый сеанс не записывает данные после удаления.
- Прерываются экспорт и превью, освобождаются Canvas и все активные Blob-ссылки. Удаляются localStorage/sessionStorage редакторов и Cache Storage расширения. Новых разрешений нет.
- Отдельная кнопка очистки системного буфера обмена. Скачанные пользователем файлы не удаляются.
- ResizeObserver больше не меняет layout синхронно во время доставки уведомлений: используется requestAnimationFrame, проверка одинаковых размеров и стабильное место под scrollbar. Сообщения ошибок не скрываются.
- README объясняет хранение оригинала/координат Crop, границы очистки, управление памятью Chrome и различие между журналом ошибок Chrome и базой снимков.
- 23 unit-теста, проверка синтаксиса 16 JS-файлов и 26 проверок в Chrome на macOS: удаление всей базы и orphan-кадров, всех редакторов, Blob URL, web storage/Cache Storage, очистка во время экспорта/захвата, восстановление страницы, отсутствие отложенных записей, повторная очистка и новый снимок. Windows напрямую не запускалась.

## 1.0.2 — 17 октября 2026

- «Сохранить» экспортирует одно изображение; обязательное разбиение по прежнему бюджету 16 мегапикселей убрано.
- Большие PNG собираются полосами в один стандартный файл с локальным deflate-сжатием, CRC и несколькими IDAT-блоками. Нет полноразмерного Canvas и изменения разрешения.
- Для JPEG доступен один файл в пределах 32767 px по стороне и 64 мегапикселей; для больших областей предлагается PNG.
- Добавлена отдельная кнопка «Частями» для ручного разбиения.
- Проверены размеры 3817 × 5413 и 3817 × 10190 из пользовательского JSON: один PNG и JPEG, нативное декодирование, точные размеры, пиксели PNG на стыках. Сами изображения пользователя JSON не содержит; проверка использует искусственные кадры этих размеров.
- 23 unit-теста и 20 проверок в Chrome на macOS; отдельно проверен один PNG высотой 20 000 px.

## 1.0.1 — 17 октября 2026

- Исправлена ошибка согласования границ PNG при дробном масштабе, включая 150% и сочетание 4K / Chrome 100%.
- Подтверждённый размерами PNG DPR имеет приоритет над отношением к округлённому `innerWidth`.
- Склейка проверяет фактические доступные пиксели каждого кадра. Допускается небольшая погрешность внешнего края из-за округления CSS; внутренние пропуски и существенная нехватка содержимого не маскируются.
- Учтены дробный `visualViewport`, разные варианты включения полос прокрутки в PNG и небольшая квантизация прокрутки между колонками.
- Добавлена локальная выгрузка численной диагностики при ошибке, без изображения и URL страницы.
- 18 unit-тестов; Chrome-прогоны при DPR 1,25 и 1,5. На pipl.io воспроизведено расхождение последнего кадра на 1 px и проверена новая склейка.
- Chrome тестировался на macOS, не на Windows. Повторная проверка на ПК пользователя необходима.

## 1.0.0

Первоначальная версия: полный захват страницы, локальная IndexedDB, Crop, PNG/JPEG, буфер обмена и экспорт крупных областей по частям.
